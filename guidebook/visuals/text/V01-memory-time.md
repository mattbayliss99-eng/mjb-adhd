# V01 four experiences

Not a sequence. Not all established ADHD manifestations.

1. Losing an intention: the plan drops before the action.
2. Losing track of time: clock time passes; the activity may still be remembered.
3. Automatic familiar activity: a practised action with little attention; often reconstructable afterwards.
4. Actual gap in awareness: a period that cannot be accounted for. Needs its own assessment.

No arrows. No diagnosis.
