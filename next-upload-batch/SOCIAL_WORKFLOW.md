# MJB — Social media lightweight workflow (staging draft)

Goal: make public sharing a low-effort extension of existing MJB website work rather than a new content-production burden.

1. ONE-TIME: establish one official MJB profile with matching name, image, site link, description and optional pinned introduction. Add a second platform only after the first works reliably.
2. REUSE: every verified site article gets a short summary, a permanent canonical URL, and preview metadata suitable for Facebook/X.
3. CAPTURE: posts, comments and misconceptions become candidate topics only if they're evidence-rich and reusable; route them to the next-upload-batch queue.
4. COMPOSE: prepare one concise social post from each finished page, plus one optional short comment-response version.
5. APPROVE: keep drafts and a simple log of queued / approved / posted, platform, date and live URL. Never send or publish without authorisation.
6. REVIEW: measure clicks and substantive engagement rather than likes alone; revise useful evergreen pages rather than duplicating content.

Minimal run: choose one existing verified article → copy a short summary and direct URL → approve/post → record public link. No daily posting obligation.

Notes for later: evaluate scheduling support via connected social-management tools; distinguish public Facebook pages from groups and check platform permissions before assuming automated posting is possible.

This file is an editorial plan only; it does not represent a connected social account or a published post.
