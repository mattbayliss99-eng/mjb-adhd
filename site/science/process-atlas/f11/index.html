Cognitive functions and observable outcomes

A cognitive profile includes several functions and several kinds of measurement. No single transmitter amount predicts the entire cognitive profile.

What the diagram shows

The diagram separates overlapping cognitive functions from the measures used to study them. Laboratory performance and lived experience supply different information. Task and state can change the expression of difficulties; a biological association does not allow one to infer an individual function directly from a neurotransmitter level. This is an organising explanation, not a scale, mechanism claim or assertion that every named difficulty must be present in every person with ADHD.
