The library · records and resources

Living archive

This website stays short and stable. The fuller record lives in the MJB ADHD library on Google Drive, which is added to over time: articles, dated sources, visuals and downloads for every part of the site.

How the library is organised

Each area has the same four public folders:

  • Articles — publishable pieces, numbered in the order they were added.
  • Sources — the supporting records behind those pieces.
  • Visuals — images and graphics.
  • Downloads — PDFs and files meant for visitors to keep.

Files are dated and may be superseded. Check the issuing organisation for the current version of any policy or guidance. Some folders are still being filled. Nothing in the library is medical advice.
